**241 TECH TIENDA VIRTUAL DE DISPOSITIVOS**

241 Tech Zone es una plataforma e-commerce web interactiva, moderna y responsiva orientada al sector tecnológico. Permite explorar productos de diversas categorías, ver ofertas destacadas, interactuar con un carrusel dinámico, gestionar un carrito de compras interactivo y generar comprobantes de compra impresos/digitales.


**Características Principales**

**Modo Claro / Oscuro (Theme Switcher):** Conmutador dinámico de temas claro/oscuro en la barra superior.

**Carrusel de Ofertas Destacadas:** Rotación automática e interactiva con ofertas exclusivas (incluyendo la gama **Redmi**).

**Catálogo de Productos y Filtros:** Filtrado dinámico por categorías (*Laptops, Smartphones, Audífonos, Smartwatches, Tablets*) y buscador en tiempo real.

**Carrito de Compras Interactivo:** Cálculo automático de subtotal e impuestos (IVA 13%), con gestión de cantidades.

**Registro de Clientes y Recibo Digital:** Formulario modal de registro de usuario y generación de comprobantes de compra en formato imprimible.

**Diseño 100% Responsivo:** Interfaz adaptada para pantallas móviles, tablets y monitores de escritorio.

---

**Tecnologías Utilizadas**

* **HTML5:** Estructura semántica de la aplicación web.

* **Tailwind CSS (CDN):** Framework de estilos utilitarios para un diseño moderno y fluido.

* **JavaScript (Vanilla / ES6+):** Lógica del DOM, estado del carrito, filtros, carrusel y conmutación de temas.

* **Lucide Icons:** Iconografía vectorial interactiva.

* **Google Fonts (Inter):** Tipografía estilizada para interfaces digitales.

## Estándares de Codificación

El código fuente ha sido refactorizado y documentado bajo los siguientes estándares de nomenclatura:

* **`PascalCase`:** Clases, controladores y modelos lógicos (*Ej. `ShoppingCartManager`, `ProductCatalog*`).
* **`camelCase`:** Variables, funciones y eventos del DOM (*Ej. `userShoppingCart`, `toggleThemeMode()`, `renderProducts()*`).
* **`UPPER_SNAKE_CASE`:** Constantes globales de configuración (*Ej. `TAX_RATE`, `DEFAULT_THEME`, `SLIDE_AUTOPLAY_INTERVAL_MS*`).
